Indexes every folder of the selected account (or every account, if left on "All accounts") locally, so drafts can pull in relevant context from past emails -- or, once an account is selected, only the specific folders you check below, so a huge mailbox doesn't have to be scraped in full. This always runs through local Ollama for embeddings, never through the Remote/LiteLLM proxy, regardless of which backend you pick for drafting -- your mailbox never leaves this machine for this feature. On Thunderbird versions older than 121, automatic indexing only covers inbox-type folders as mail arrives; the periodic pull below is what covers every other folder.

Narrowing to one account (or to specific folders within it) immediately stops the excluded content from being used in drafts, even for anything already indexed from it -- but it won't delete that old data from disk.
